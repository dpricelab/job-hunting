Job hunt

Checks the careers pages of the publishers you care about, keeps only the roles that fit your rules, and shows them on one page with closing dates and buttons to mark what you have applied for. It runs on your own computer; nothing is sent anywhere.

Which computer are you using?

1. Install Python (once)

  1. Go to python.org/downloads and click the yellow Download Python button.
  2. Open the downloaded file and click Continue through the installer, then Install. It may ask for your Mac password.

Already have Python 3.10 or newer? Skip this step.

2. Install Job hunt (once)

  1. In the folder you downloaded, double-click Install (Mac).
  2. The first time, your Mac will refuse with a message that it “could not verify” the file. That is normal for anything downloaded that is not from the App Store. Click Done, then:
    • open System Settings → Privacy & Security,
    • scroll down to “Install (Mac).command was blocked” and click Open Anyway, then Open.
    On older Macs: right-click Install (Mac), choose Open, then Open again.
  3. A window with text opens and sets everything up. It takes about a minute and finishes by opening a folder called Job hunt in your Documents.

You only need to allow it once: the installer clears the warning for everything else.

3. Every day

  1. Open Documents → Job hunt and double-click Open job board.
  2. It spends a minute or two checking every careers page, then opens your job board in your web browser.
  3. When you have finished, close the text window (click Terminate if asked).

Tip: drag Open job board to your Dock, to the right of the dividing line, to open it from there.

1. Install Python (once)

  1. Go to python.org/downloads and click the yellow Download Python button.
  2. Run the downloaded file. On its first screen, tick “Add python.exe to PATH”, then click Install Now.

Already have Python 3.10 or newer? Skip this step.

2. Install Job hunt (once)

  1. Right-click the downloaded zip file and choose Extract All…, then Extract. (Double-clicking the zip only lets you look inside; the installer will not work from there.)
  2. In the extracted folder, double-click Install (Windows).
  3. If a blue box says “Windows protected your PC”, click More info, then Run anyway. If a box asks whether to run the file, click Run.
  4. A black window sets everything up. It takes about a minute and finishes by opening a folder called Job hunt in your Documents. Press any key to close the black window.

3. Every day

  1. Open Documents → Job hunt and double-click Open job board.
  2. It spends a minute or two checking every careers page, then opens your job board in your web browser.
  3. When you have finished, close the black window.

Tip: right-click Open job board → Send to → Desktop (create shortcut) to open it from your desktop.

Using the job board

  • Each card is an open role. Click its title to read the advert.
  • Applied and Not for me take a role off your list. Undo puts it back. Nothing else to save.
  • New marks roles that appeared since you last looked. A red label means it closes within a week.
  • The box at the top filters by any word: a company, a place, a job title.

Changing what it looks for

Double-click Edit my settings in your Job hunt folder. The settings open in a text editor; change them, save, and it checks them for you. The parts worth changing:

  • title_include — a role is only shown if its title contains one of these words. Add your own on a new line, for example - marketing.
  • title_exclude — roles whose titles contain these are never shown.
  • location_include — the places you would work. Add a town on a new line, for example - Bristol.
  • companies — the careers pages checked. To stop checking one, add a line enabled: false under it, lined up with the lines above.
The settings file is fussy about layout. Keep each new line starting with the same spaces and - as the lines around it, and do not use tabs. Lines beginning re: are patterns; plain words work fine on their own. If you get stuck, the checker says which line it could not read.

Updating to a newer version

Download the new version, unzip it and double-click Install again. Your settings and everything you have marked are kept.

Something not working?

  • “Python 3.10 or newer is needed” — do step 1, then run Install again. On Windows, if you already installed Python, run its installer again, choose Modify and make sure “Add Python to environment variables” is ticked.
  • “The install did not finish” — it needs the internet to fetch two small parts. Check you are online and try again.
  • A company shows a ✗ when checking — that site was unreachable just then. The rest still work, and the next check usually succeeds.
  • The board does not open — type http://127.0.0.1:8765 into your browser while the text window is open.

Removing it

Delete the Job hunt folder in Documents. The program itself is in ~/Library/Application Support/jobhunt on a Mac and %LOCALAPPDATA%\jobhunt on Windows, and can be deleted too.
