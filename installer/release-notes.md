**For Mac and Windows. No coding needed.**

1. Download the **jobhunt** zip file below (under *Assets*) and unzip it.
2. Open **START HERE** in the unzipped folder and follow the steps for your computer:
   install Python once, double-click **Install**, then double-click **Open job board**
   whenever you want to look.

Updating from an earlier version: download this one and double-click Install again.
Your settings and the roles you have marked are kept.
